# Extract pure geometry utilities from useTrackEditor.js (stage 6, ADR 0032)

`useTrackEditor.js` (2247 LOC) owns 8 concerns: geometry editing, POI management, elevation preview, routing/WASM, undo/redo, GPX export, server CRUD, and segment operations. The first extraction pulls pure functions into `editor/trackGeometryUtils.js` (11 functions, 197 LOC) — `geojsonToPoints`, `pointsToGeoJSON`, `calcSegmentDistance`, `isValidCoord`, `createEmptySegment`, `getDefaultSegmentColor`, `toMeters`, `distancePointToSegmentMeters`, `findNearestPointIndex`, `getNextPoiName`, `SEGMENT_COLORS`. These are pure, stateless, and independently testable (24 tests). Further extraction of stateful modules is deferred — the god composable's internal functions have closure dependencies on shared refs that require careful interface design to extract safely. Note: the composable's internal `createEmptySegment`, `findNearestPointIndex`, and `getNextPoiName` have different signatures than the extracted utilities (they depend on closure state) and remain in the composable.
