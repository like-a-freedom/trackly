# Extract pure geometry utilities from useTrackEditor.js (stage 6, ADR 0032)

`useTrackEditor.js` (2250 LOC) owns 8 concerns: geometry editing, POI management, elevation preview, routing/WASM, undo/redo, GPX export, server CRUD, and segment operations. The first extraction step pulls pure functions into `editor/trackGeometryUtils.js` (11 functions, 197 LOC) — `geojsonToPoints`, `pointsToGeoJSON`, `calcSegmentDistance`, `isValidCoord`, `createEmptySegment`, `getDefaultSegmentColor`, `toMeters`, `distancePointToSegmentMeters`, `findNearestPointIndex`, `getNextPoiName`. These are pure, stateless, and independently testable. Further extraction of stateful modules (useTrackGeometry, useTrackPois, useElevationPreview, useTrackRouting, useTrackSave, useTrackExport) is deferred — the god composable's internal functions have closure dependencies on shared refs that require careful interface design to extract safely.
