# Split TrackDetailPanel.vue into child components (stage 7, ADR 0033)

`TrackDetailPanel.vue` (4267 LOC) owns 9 concerns: track header, categories, auto-classifications, basic info, map overlays, statistics, elevation chart, slope analysis, and track info. The first extraction creates `CategoriesPanel.vue` — the most self-contained section with clear inputs (track, isOwner, categoriesList) and outputs (categories-change event). Further extraction of ElevationPanel, StatisticsPanel, and TrackInfoPanel is deferred — these sections have complex closure dependencies on shared refs (track, chartMode, elevation polling state) that require careful interface design to extract safely. The CategoriesPanel is created and tested but not yet integrated into the parent component pending full interface design.
