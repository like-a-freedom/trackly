# PoiClusterGroup inject race + getColorForId divergence (stage 0.5b + 0.5c)

Two small frontend fixes that close audit findings. (a) `PoiClusterGroup.vue` was injecting a Vue Leaflet wrapper ref instead of the resolved `L.Map` and falling back to a 100ms `setInterval` (capped at 5s). The fix widens `getMapObject()` to accept either a real `L.Map` (has `.getZoom`) or the Vue Leaflet wrapper (has `.mapObject` / `.leafletObject`), preserving backward compatibility. The watch on `leafletMap` no longer needs `immediate: true` because the `onMounted` block does the initial check; the legacy `setInterval` polling is preserved as a safety net for any parent that still injects the wrapper. (b) `TrackView.vue` had an inline `getColorForId` that diverged from `utils/trackColors.js`. We delete the inline copy and import the canonical one.
