# Project documentation strategy: CONTEXT.md + ADR catalog (stage 6)

The project lacked a domain glossary and a single entry point for agentic workers and new contributors. We create `CONTEXT.md` at repo root with the full domain glossary (Track, Track Detail, POI, User, Session, Auth, etc.) and a "Deferred follow-ups" section listing known large files. The 24 ADRs (0001–0024) document every architectural decision made during the remediation. Future agents should consult `CONTEXT.md` first, then the ADR catalog in `docs/adr/` for rationale.
